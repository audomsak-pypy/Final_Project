# Adidur — จริงหรือเฟค
### AI ข่าวปลอม และภัยออนไลน์: มองโลก เปรียบเทียบไทย

เว็บแอปพลิเคชันแดชบอร์ดแบบโต้ตอบ (Interactive Dashboard) พัฒนาด้วย **Python (Dash) + Plotly + SQLite** สำหรับสำรวจแนวโน้มเหตุการณ์ Deepfake ทั่วโลก สถิติข่าวปลอมเกี่ยวกับ AI ในไทย คดีหลอกลวงและความเสียหายออนไลน์ ประเด็นข้อมูลบิดเบือนระหว่างประเทศ และคะแนนเสรีภาพอินเทอร์เน็ต

## 2. ขั้นตอนการติดตั้งและรันโปรเจกต์

รันคำสั่งต่อไปนี้ตามลำดับในเทอร์มินัล (ภายในโฟลเดอร์ `adidur`):

```bash
# 1. ติดตั้ง Dependencies
pip install -r requirements.txt

# 2. สร้างฐานข้อมูล SQLite จากไฟล์ข้อมูลดิบ
python scripts/build_db.py data/raw data/adidur.db

# 3. รันสคริปต์ตรวจสอบค่าคาดหวัง SQL
python scripts/expected_values.py data/adidur.db

# 4. รันชุดทดสอบอัตโนมัติ (Automated Tests)
pytest -q

# 5. เปิดใช้งานเว็บแดชบอร์ด
python -m app.app
```

เปิดเว็บเบราว์เซอร์ไปที่: **http://127.0.0.1:8050**

- **E02 (ข่าว AI):** รวม 56 โพสต์ (mention 33, media_evidence 23) ปี 2025 = 11, ปี 2026 = 44
- **E04 (Deepfake AIID):** ปี 2024 = 140, ปี 2025 = 235 และยอดรวมทั้งฐาน 588 เรื่อง
- **E06 (ACSC):** รวมทุกสัปดาห์ 381,390 คดี มูลค่า 18,177,373,771 บาท (เฉลี่ย 47,660.86 บาท/คดี) / ไม่รวม suspect 302,079 คดี มูลค่า 15,402,373,771 บาท (เฉลี่ย 50,987.90 บาท/คดี)
- **E08 (สัปดาห์ขาด ACSC):** พบ 3 สัปดาห์ขาด ได้แก่ `2026-06-14`, `2026-07-26`, `2026-10-25`

- **E12 (FOTN อาเซียน 2024):** ไทยได้ 39 คะแนน อยู่อันดับ 6 จาก 8 ประเทศ
- **E15 (ประเด็น 2020–2022):** ตัวหาร EU = 4,820, AFNC = 3,556 และโควิด-19 EU 629 เรื่อง (13.0%) / AFNC 657 ข่าว (18.5%)

### เกณฑ์ข้อ B (กติกาการเชื่อมโยงข้อมูลใน `tests/test_rules.py`):
- สลับตัวกรองหมวดข่าว AI แล้วผลรวมคดีและความเสียหายของ ACSC ไม่เปลี่ยนแปลง (ไม่มีตัวเชื่อม)
- เลือกประเทศอื่นในแท็บ 3 แล้วสถิติคำตัดสิน AFNC ในกราฟ C3.3 ไม่เปลี่ยน (แสดงข้อมูลไทยเท่านั้น)
- ไม่มีแถว ACSC ที่ cases = 0 และคิวรี C1.5 ได้ครบ 51 สัปดาห์ปฏิทิน (มีค่า 48 สัปดาห์, เว้นว่าง 3 สัปดาห์)
- ไฟล์ดาวน์โหลด CSV ส่งออกขึ้นต้นด้วย UTF-8 BOM (`\xef\xbb\xbf`) แสดงผลภาษาไทยใน Excel ถูกต้อง
- การแปลง State <-> URL Query String ทำงานแบบ Two-way Round-trip ได้สถานะเดิมอย่างถูกต้อง

## 4. วิธี Deploy บนคลาวด์ (Render / Web Service)

เนื่องจาก Dash ทำงานโดยมี Flask เป็น Python Backend Server จึงไม่สามารถ Deploy บน Static Hosting อย่าง GitHub Pages ได้โดยตรง วิธีการ Deploy บนบริการที่รองรับ Python เช่น **Render** มีดังนี้:

1. สร้างบัญชีที่ [Render.com](https://render.com) และสร้างบริการแบบ **Web Service** เชื่อมกับ GitHub Repository
2. ตั้งค่า Configuration:
   - **Environment:** `Python 3`
   - **Build Command:**
     ```bash
     pip install -r requirements.txt && python scripts/build_db.py data/raw data/adidur.db
     ```
   - **Start Command:**
     ```bash
     gunicorn app.app:app.server -b 0.0.0.0:$PORT
     ```
3. (ทางเลือก) ติดตั้ง `gunicorn` เพิ่มใน environment:
   ```bash
   pip install gunicorn
   ```
4. กด Deploy ระบบจะสร้างฐานข้อมูล `adidur.db` และเปิดรันแดชบอร์ดออนไลน์พร้อมใช้งานทันที

## 5. การเปลี่ยนแปลงจากสเปกและข้อควรระวัง (Deviations from Spec)

1. **ช่วงเริ่มต้นของแท็บ 2 ปรับเป็น พ.ศ. 2563–2565 (ค.ศ. 2020–2022):**
   - ในสเปกเดิมระบุช่วง 2562–2565 แต่จากการตรวจข้อมูลจริงพบว่า AFNC เริ่มเก็บข้อมูลอย่างเป็นทางการตั้งแต่ ต.ค. 2562 (มีข้อมูลเพียง 3 เดือน ไม่เต็มปี) หากนำมาคำนวณสัดส่วนรายปีจะทำให้ตัวเลขบิดเบือน จึงเปลี่ยนค่าเริ่มต้นเป็น 2563–2565 เพื่อให้เป็นปีเต็มที่เปรียบเทียบได้อย่างสมบูรณ์
2. **จำนวนข่าว AI ของ AFNC เป็นค่าขั้นต่ำ:**
   - ไฟล์ Excel `afnc_items` มีการตัดข้อความ `content` เหลือเพียง 500 ตัวอักษร ทำให้การตรวจจับคำด้วย Regex พบ 56 ข่าว ซึ่งเป็นค่าขั้นต่ำในข้อความช่วงต้น
3. **การแยกสัปดาห์น่าสงสัยของ ACSC:**
   - สัปดาห์ที่ 16–22 ส.ค. 2569 มียอดคดีสูงผิดปกติถึง 79,311 คดี (สูงกว่าปกติประมาณ 13 เท่า คาดว่าเป็นยอดสะสม) แดชบอร์ดจึงจัดให้มีสวิตช์เปิด-ปิดการรวมสัปดาห์นี้ เพื่อให้เห็นแนวโน้มจริงที่ไม่ถูกดึงด้วยค่าผิดปกติ
4. **ความเสียหายของ ACSC ตั้งแต่ ส.ค. 2569:**
   - ตัวเลขในแถลงข่าวถูกปัดเศษเป็นหลักร้อยล้าน/พันล้านบาท กราฟ C1.6 จึงใช้สัญลักษณ์จุดกลวง (hollow circle) แสดงจุดที่มีการปัดเศษ
5. **ข้อสรุปที่ห้ามเขียน:**
   - ห้ามสรุปว่า AI หรือข่าวปลอมทำให้คดีหลอกลวงเพิ่มขึ้น
   - ห้ามสรุปว่าประเทศไทยมีข่าวปลอมตามหลังโลก
   - ห้ามสรุปความสัมพันธ์ระหว่างคะแนนเสรีภาพอินเทอร์เน็ตกับปริมาณข่าวปลอม
