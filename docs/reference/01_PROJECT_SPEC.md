## 3. คำถามและเส้นเรื่อง

เส้นเรื่อง: **โลกเห็นอะไร → ไทยเจออะไร → ความเสียหายในไทย → ประเด็นที่ปรากฏร่วมกัน → บริบทเสรีภาพ**

| รหัส | คำถาม | ข้อมูลรองรับไหม |
|---|---|---|
| Q1 | เหตุการณ์ Deepfake ที่บันทึกทั่วโลกใน AIID เปลี่ยนแปลงอย่างไรรายปี | ได้ ตามเกณฑ์คำค้น และขึ้นกับว่าเหตุการณ์ถูกบันทึกหรือไม่ |
| Q2 | ข่าวที่เกี่ยวกับ AI ซึ่ง AFNC ตัดสินว่าเป็นเท็จ มีแนวโน้มและหมวดอย่างไร ข่าวไหนมียอดเข้าชมสูงสุดและต่ำสุดในช่วงที่เลือก | ได้ แต่จำนวนน้อย (56) และเป็นค่าขั้นต่ำ |
| Q3 | ช่วงเดียวกัน คดีหลอกลวงออนไลน์ในไทย (ACSC) มีจำนวนและความเสียหายเปลี่ยนอย่างไร | ได้เฉพาะ 9 พ.ย. 2568 – 24 ต.ค. 2569 **ตอบไม่ได้ว่าคดีใดเกี่ยวกับ AI** |
| Q4 | ประเด็นใดปรากฏร่วมกัน และประเด็นใดมีสัดส่วนต่างกัน ระหว่าง EUvsDisinfo กับข่าวเท็จของ AFNC | ได้บางส่วน: เทียบตรงได้ใน 4 ประเด็นที่ใช้คำค้นทั้งสองฝั่ง ส่วนอีก 3 ประเด็นวิธีจัดกลุ่มต่างกัน |
| Q5 | ไทยมีคะแนนเสรีภาพอินเทอร์เน็ตอยู่ตรงไหนเมื่อเทียบกับประเทศอื่น และในช่วงเดียวกัน AFNC เผยแพร่ผลตรวจข่าวจำนวนเท่าไร | ได้ในเชิงพรรณนา **ตอบไม่ได้ว่าเสรีภาพสัมพันธ์กับปริมาณข่าวปลอม** |

**ข้อสรุปที่ห้ามเขียน**

- AI หรือข่าวปลอมทำให้คดีเพิ่ม
- ไทยตามหลังโลก N ปี
- ประเด็นแพร่หรือข้ามมาจากต่างประเทศ
- ประเทศเสรีน้อยมีข่าวปลอมน้อยกว่า
- ประเทศต้นทางของข้อมูลบิดเบือน (อนุมานจากภาษาหรือโดเมน)
- ยอดเข้าชมสูงแปลว่าข่าวรุนแรงหรือน่าเชื่อถือ
- จำนวนข่าวของ AFNC คือปริมาณข่าวปลอมในสังคม

## 5. แท็บ ตัวกรองร่วม และการเชื่อมกราฟ

**ลำดับในแต่ละแท็บ:** คำถามหลัก → ตัวกรอง → KPI → กราฟ → ตารางหลักฐาน → คำอธิบายและข้อจำกัด

**state ต่อแท็บ** (เก็บใน dcc.Store แยก 4 ก้อน และซิงก์กับ URL query เพื่อแชร์ลิงก์)

```text
tab1 = { y0, y1, level: "year"|"month"|"items", year, month,
         levels: ["mention","media_evidence"], category, imp,
         acsc_level: "month"|"week", acsc_month, acsc_week, inc_suspect: true }
tab2 = { y0: 2020, y1: 2022, level, year, month, theme, afnc_category }
tab3 = { fy: 2024, groups: ["ASEAN"], add_rus: false, level: "group"|"country"|"year", iso3 }
tab4 = { dataset }
URL ตัวอย่าง: /?tab=1&y0=2025&y1=2026&year=2026&levels=media_evidence
```

**กติกาการเชื่อม**

1. คลิกกราฟใดก็ตาม = แก้ state ก้อนเดียว แล้ว callback เดียว render ทุกองค์ประกอบของแท็บใหม่
2. มิติที่เชื่อมได้จริงเท่านั้นที่กรองข้ามกราฟ
   - **เวลา** เชื่อมทุกชุด
   - **ประเด็น** เชื่อม EU กับ AFNC
   - **หมวดและระดับ AI** เชื่อมเฉพาะ AFNC
   - **ประเทศ** เชื่อมเฉพาะ FOTN
3. กราฟที่มิตินั้นไม่เชื่อม แสดงป้ายตัวหนังสือ "ตัวกรอง <ชื่อ> ไม่มีผลกับกราฟนี้" และ**คงค่าเดิม** ไม่เปลี่ยนเป็น 0
4. ช่วงที่ชุดใดไม่มีข้อมูล แสดงข้อความว่างแบบมีเหตุผล เช่น "ไม่มีข้อมูล ACSC ก่อน 9 พ.ย. 2568"
5. **Drill down / up** ทุกระดับมี breadcrumb และปุ่ม "ย้อนระดับ"
   - AIID/AFNC: ทั้งหมด › 2568 › ก.ค. 2568 › รายการ
   - ACSC: ทุกเดือน › ส.ค. 2569 › สัปดาห์ 16–22 ส.ค. (+ ลิงก์ข่าวต้นทาง)
   - FOTN: อาเซียน 2567 › ไทย › ปีข้อมูล 2567 (องค์ประกอบ)
6. แถบตัวกรองที่ใช้อยู่แสดงเป็นชิป กดชิปเพื่อลบทีละตัว มีปุ่ม "ล้างตัวกรอง"
7. ทุกตารางและการ์ดข่าว แตะแล้วเปิดลิงก์ต้นทางในแท็บใหม่ (url / source_url / article_url / ลิงก์ AIID)
8. ใช้งานด้วยการแตะได้ทั้งหมด
   - `clickmode='event+select'`
   - ค่าของจุดที่แตะแสดงในแผงข้อมูลใต้กราฟ ไม่พึ่ง hover

**ข้อความสรุปอัตโนมัติ**

- คำนวณจาก state ปัจจุบัน แบ่งเป็น 2 กล่อง: "ข้อค้นพบจากข้อมูล" และ "ข้อจำกัด"
- ใช้แม่แบบประโยคที่เติมตัวเลข ห้ามมีตัวเลขคงที่
- การเปลี่ยนแปลงของปี 2569 เทียบกับช่วงเดียวกันของปี 2568
  - AFNC: ม.ค.–ต.ค.
  - AIID: 1 ม.ค.–26 ต.ค.
  - ACSC ไม่มีปีก่อนให้เทียบ แสดง "คำนวณไม่ได้"
- ฐานเป็น 0 หรือข้อมูลขาด แสดง "คำนวณไม่ได้"
- ฐานน้อยกว่า 10 แสดงจำนวนคู่กับ %

## 7. คำอธิบายศัพท์ (ส่วน "ค่าแต่ละค่าคืออะไร")

| คำ | คำอธิบาย |
|---|---|
| Deepfake | ภาพ เสียง หรือวิดีโอที่ใช้ AI สร้างหรือดัดแปลงให้ดูเหมือนคนจริงพูดหรือทำสิ่งที่ไม่ได้ทำ ในเว็บนี้นับจากคำค้นใน AIID |
| Misinformation | ข้อมูลที่ไม่ถูกต้อง ในเว็บนี้หมายถึงเหตุการณ์ใน AIID ที่กลุ่มวิจัย MIT จัดไว้ใน Risk Domain "Misinformation" |
| ข่าวปลอม | คำตัดสินของ AFNC ว่าเนื้อหาไม่เป็นความจริง |
| ข่าวบิดเบือน | คำตัดสินของ AFNC ว่ามีส่วนจริงแต่ถูกนำเสนอให้เข้าใจผิด |
| ข่าวเท็จ (ในเว็บนี้) | ข่าวปลอม + ข่าวบิดเบือน |
| การหักล้าง (debunk) | บันทึก 1 เรื่องของ EUvsDisinfo ที่อธิบายว่ากล่าวอ้างอะไรและทำไมไม่จริง |
| คะแนนเสรีภาพอินเทอร์เน็ต | คะแนน 0–100 จาก Freedom House ยิ่งสูงยิ่งเสรี มี 3 ส่วน: การเข้าถึง /25, การจำกัดเนื้อหา /35, การละเมิดสิทธิผู้ใช้ /40 |
| ปีข้อมูล / ปีรายงาน | ปีที่การประเมินครอบคลุม / ปีที่รายงานตีพิมพ์ (ปีรายงาน = ปีข้อมูล + 1) |
| ยอดเข้าชม | view_count ณ 1 พ.ย. 2569 สะสมตั้งแต่วันโพสต์ ไม่ใช่ความน่าเชื่อถือหรือความรุนแรง |

## 8. ส่วน "ทำไมจึงจัดทำ Dashboard นี้" (ร่าง)

- AI ทำให้สร้างภาพ เสียง และวิดีโอปลอมได้ง่ายขึ้น
- ศูนย์ต่อต้านข่าวปลอมและศูนย์ต่อต้านการฉ้อโกงออนไลน์เผยแพร่ข้อมูลที่ช่วยให้เห็นภาพในไทย
- แดชบอร์ดนี้วางข้อมูลจากหลายแหล่งไว้บนแกนเวลาเดียวกัน เพื่อให้ผู้ใช้เห็นว่าแต่ละแหล่งบันทึกอะไรไว้ และกดดูหลักฐานต้นทางได้เอง
- ข้อมูลเหล่านี้บันทึกคนละสิ่ง จึงใช้เทียบช่วงเวลาและประเด็นได้ แต่ใช้สรุปสาเหตุไม่ได้
