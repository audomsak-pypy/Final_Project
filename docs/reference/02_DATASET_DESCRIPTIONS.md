## 1. AI Incident Database (AIID)

- **ผู้จัดทำ:** Responsible AI Collaborative
- **ไฟล์:** ฉบับส่งออก 26 ต.ค. 2569 ชีต Incidents
- **1 แถว = 1 เหตุการณ์** (1,775 แถว, Incident ID ไม่ซ้ำ 1,775)
- **ช่วงวันที่เกิดเหตุ:** 26 ก.ย. 2526 – 22 ต.ค. 2569 (ส่วนใหญ่ตั้งแต่ 2558)

| คอลัมน์ | ชนิด | ค่าว่าง | ใช้ทำอะไร |
|---|---|---|---|
| Incident ID | int | 0 | คีย์หลัก |
| date / year | date / int | 0 | แกนเวลา (year ตรงกับปีของ date ทุกแถว) |
| title, description | text | 0 | ค้นคำ deepfake และแสดงในตารางหลักฐาน |
| Implicated Systems | text (หลายค่า) | 549 | ค้นคำ deepfake |
| deployer / developer / harmed | text (หลายค่าคั่นจุลภาค) | 3 / 1 / 2 | แสดงในรายละเอียดเท่านั้น |
| report_count | int | 0 | จำนวนข่าวที่รายงานเหตุการณ์ (มัธยฐาน 2, สูงสุด 58) |
| Risk Domain (MIT) | text | 279 | ใช้หา Misinformation (196 เหตุการณ์) |
| Intent | text | 279 | Intentional / Unintentional / Other |
| Country Code | text | 1,632 | **ไม่ใช้เชื่อมประเทศ** มีเพียง 143 แถวและไม่มี TH |

**การเตรียมข้อมูล**

- `is_deepfake` (ตั้งเอง) = 1 ถ้า title + description + Implicated Systems ตรงกับ regex `deep\s?-?fake|voice[- ]clon|face[- ]?swap|synthetic (voice|video|media|image)` (ไม่สนตัวพิมพ์) ได้ 588 เหตุการณ์
  - คู่มือบอกว่าค้นคำ Deepfake เฉพาะใน Implicated Systems พบ 439 เหตุการณ์ ตัวเลขต่างกันเพราะเราค้นหลายคอลัมน์และหลายคำ
- `is_misinfo` = 1 ถ้า Risk Domain มีคำว่า Misinformation
- `url` = `https://incidentdatabase.ai/cite/<Incident ID>` เป็นรูปแบบลิงก์ที่ประกอบขึ้นเอง ควรสุ่มเปิดตรวจ 2–3 ลิงก์

**จุดที่ตีความผิดได้**

- นับได้เฉพาะเหตุการณ์ที่เป็นข่าวและมีคนบันทึก ข่าวที่บันทึกเอนไปทางภาษาอังกฤษและสหรัฐฯ จึงไม่ใช่จำนวนเหตุการณ์จริงทั้งโลก
- ปีล่าสุดอาจต่ำกว่าความจริง เพราะฐานข้อมูลเพิ่มเหตุการณ์ย้อนหลังต่อเนื่อง (คู่มือบอกว่าเพิ่มราว 14 เหตุการณ์ต่อสัปดาห์) ไม่แน่ใจว่าล่าช้ามากแค่ไหน
  - ช่วงเดียวกัน 1 ม.ค.–26 ต.ค.: ปี 2568 มี 194 เหตุการณ์ ปี 2569 มี 126 เหตุการณ์
  - ห้ามสรุปว่า Deepfake ลดลง

## 2. Freedom on the Net (FOTN)

- **ผู้จัดทำ:** Freedom House ผ่าน QoG Standard Dataset (ม.ค. 2026) มหาวิทยาลัยโกเธนเบิร์ก
- **1 แถว = 1 ประเทศ ใน 1 ปีข้อมูล** (940 แถว, 72 ประเทศ, ไม่มีแถวซ้ำ iso3 + data_year)
- **ช่วงปี:** data_year 2553–2567 ซึ่งตรงกับ report_edition 2554–2568 (report_edition = data_year + 1 ทุกแถว)

| คอลัมน์ | ชนิด | หน่วย/ช่วง | หมายเหตุ |
|---|---|---|---|
| iso3 | text | | คีย์ประเทศ ใช้แทนการจับคู่ชื่อ |
| country | text | | ชื่อรูปแบบ ISO เช่น "Philippines (the)" ต้องมีชื่อไทยแสดงผล (country_th, ตั้งเอง) |
| data_year / report_edition | int | | ใช้ data_year เป็นแกนเวลา และแสดง report_edition คู่กันเสมอ |
| total_score | int | 0–100 | สูง = เสรีมาก ค่าจริง 9–96 |
| obstacles_to_access | int | เต็ม 25 | |
| limits_on_content | int | เต็ม 35 | |
| violations_of_user_rights | int | เต็ม 40 | |
| status_code / status / status_th | int / text | 1 เสรี, 2 เสรีบางส่วน, 3 ไม่เสรี | |

**ผลตรวจ**

- ไม่มีค่าว่าง
- total_score = ผลรวม 3 องค์ประกอบทุกแถว
- จำนวนประเทศต่อปี: 37 (2553) → 64 (2556–2562) → 69 (2563–2565) → 71 (2566–2567)
  - ประเทศที่ไม่มีในปีใดคือ "ไม่มีข้อมูล" ไม่ใช่ 0
- อาเซียนที่มีข้อมูล 8 ประเทศ: THA, MYS, IDN, PHL, VNM, MMR, KHM, SGP (ไม่มี ลาว และ บรูไน)
- เป็นการประเมินของผู้เชี่ยวชาญ ไม่ใช่การนับเหตุการณ์

## 3. EUvsDisinfo

- view_count ไม่ใช่ความน่าเชื่อถือหรือความรุนแรง

### 4.1 เกณฑ์ข่าวที่เกี่ยวข้องกับ AI (ตั้งเอง)

1. กรองเฉพาะ `item_type = 'Verdict'` และ `verdict_en IN ('Fake','Distorted')` ได้ 10,955 โพสต์
2. ทำความสะอาด `title + content` โดยลบแท็ก HTML (`<[^>]+>`) และ URL (`https?://\S+|www\.\S+`) แล้วรวมช่องว่าง
3. ระดับ `media_evidence` (ตั้งเอง: "มีคำบ่งชี้ว่าใช้ AI สร้างหรือดัดแปลงสื่อ") ตรงกับข้อใดข้อหนึ่ง
   - deepfake / ดีปเฟก / ดีพเฟค / โคลนเสียง / ปลอมเสียง / เลียนเสียง
   - (สร้าง|ทำ|ตัดต่อ|ปลอม|ดัดแปลง|เจน) + ไม่เกิน 12 ตัวอักษร + (ด้วย|โดย|จาก|ใช้) + (AI|เอไอ|ปัญญาประดิษฐ์)
   - AI + (สร้าง|ปลอม|ตัดต่อ|เจน)
   - (ภาพ|คลิป|วิดีโอ|เสียง) + ไม่เกิน 10 ตัวอักษร + (AI|เอไอ)
4. ระดับ `mention` (ตั้งเอง: "กล่าวถึง AI") คือไม่เข้าข้อ 3 แต่ตรงกับข้อใดข้อหนึ่ง
   - `AI` ตัวพิมพ์ใหญ่ที่ไม่มีตัวอักษรอังกฤษติดหน้าหรือหลัง
   - `A.I.`, artificial intelligence, ปัญญาประดิษฐ์
   - `เอไอ` ที่ไม่ตามด้วย `เอส`
   - ChatGPT / แชทจีพีที / chatbot / แชทบอท / generative
5. **ไม่ค้น `ai` ตัวพิมพ์เล็กแบบหลวม** เพื่อไม่ให้จับ Thailand, AIS, เอไอเอส, said
6. ทุกแถวเก็บ `matched_terms` และ `evidence_snippet` (ตัดรอบคำที่ตรง ±60 ตัวอักษร)
7. ทุกแถวมี `review_status = 'ต้องตรวจสอบ'` จนกว่าจะมีคนอ่านคำชี้แจงจริง
   - ระดับ media_evidence เป็นแค่ "มีคำบ่งชี้" ไม่ใช่การยืนยันว่า AI สร้างข่าวนั้น
8. ป้าย `impersonation_flag` (ตั้งเอง: "แอบอ้างหน่วยงาน/บุคคล") = พบคำว่า "แอบอ้าง"
   - เป็นวิธีการหลอก ไม่ใช่หมวดข่าว จึงแสดงแยกจาก category_th

**ผล:** ได้ 56 โพสต์ (mention 33, media_evidence 23) ตรวจทั้ง 56 รายการด้วยตาแล้ว ไม่พบการจับ AIS หรือคำอื่นผิด

- ระดับ mention ส่วนหนึ่งน่าจะเป็นภาพที่สร้างด้วย AI แต่คำชี้แจงถูกตัดก่อนถึงคำนั้น ยังไม่แน่ใจ จึงคงป้าย "ต้องตรวจสอบ"
- พบรายการปี 2564 หนึ่งรายการ ("...DNA ของมนุษย์เปลี่ยนเป็นกึ่ง AI") ซึ่งเป็นข่าวเท็จที่**กล่าวถึง AI** ไม่ใช่สื่อที่ AI สร้าง ตัวอย่างนี้แสดงว่าทำไมต้องแยกสองระดับ
