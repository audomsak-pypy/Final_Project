## ปัญหาและวัตถุประสงค์
ข้อมูล AI ข่าวที่ถูกตรวจสอบ คดีออนไลน์ และเสรีภาพอินเทอร์เน็ตมีหน่วยและกระบวนการคัดเลือกต่างกัน ผู้ใช้ต้องสำรวจหลักฐานจริงโดยไม่หลงสรุปสาเหตุจากกราฟร่วมเวลา ความสำเร็จวัดจากค่าข้อมูลอ้างอิง การกรองและส่งออกที่สอดคล้องกัน และการเปิดแอปจริง ไม่ใช้ข้อกล่าวอ้างว่าไทยตามหลังโลกหรือข่าวต่างประเทศแพร่เข้าไทยเป็นผลการศึกษา

## ผู้ใช้
ผู้เรียนต้องเตรียมข้อมูลซ้ำและตรวจสูตรได้ ผู้ประเมินต้องตามจาก requirement ถึง query และผลทดสอบได้ ประชาชนต้องอ่านไทย เลือกช่วงเวลา เปิดต้นทาง และดาวน์โหลดผลได้ ไม่แต่งชื่อผู้รับผิดชอบ ใช้ [ชื่อผู้จัดทำ] จนกว่าจะได้รับชื่อจริง

## สูตรและตัวหาร
Deepfake COUNT DISTINCT incident_id; AI COUNT DISTINCT post_id จาก afnc_ai_match แยก mention/media_evidence; คดี SUM cases; ความเสียหาย SUM loss_baht เฉพาะแถวที่มีทั้งสอง; บาทต่อคดี SUM loss / SUM cases เมื่อฐาน>0; ผลต่าง suspect คำนวณทั้งรวมและไม่รวม ขาดรายงานยัง NULL

ประเด็น numerator COUNT DISTINCT id ที่ตรงพจนานุกรม / ข่าวเท็จทั้งหมดของ AFNC หรือการหักล้างทั้งหมดของ EU ในปีนั้น ไม่ใช้จำนวนที่ match เป็นฐาน เรื่องหนึ่งหลายประเด็นได้ คะแนน FOTN สูงคือเสรีมาก อันดับใช้ RANK (เสมอแล้วข้ามอันดับ) ประเทศไม่ซ้ำในปีเดียว มัธยฐานกลุ่มในปีเดียว คำตัดสิน AFNC รวม Fake/Distorted/True ไม่เรียกทั้งหมดว่าข่าวปลอม

## User flow และ filter contract
หน้าเปิด → CTA → คำถาม → filter → KPI → ข่าว/กราฟ → หลักฐาน → ข้อค้นพบและข้อจำกัด → แหล่งข้อมูล/ดาวน์โหลด filter ใช้ปุ่มนำไปใช้เพื่ออัปเดต state พร้อมกัน
| มิติ | AIID | AFNC | ACSC | EU | FOTN |
|---|---|---|---|---|---|
| ปี/เดือน | ใช่ | ใช่ | จุดตัด coverage | ใช่ | ปีเท่านั้น |
| ระดับ AI/หมวด/แอบอ้าง (แท็บ1) | ไม่มีผล | ใช่ | ไม่มีผล | – | – |
| ประเด็น/หมวด (แท็บ2) | ไม่มีผล | ใช่ | – | ประเด็นเท่านั้น | – |
| ประเทศ/กลุ่ม (แท็บ3) | – | ไม่มีผล | – | ไม่มีผล | ใช่ |
| suspect | ไม่มีผล | ไม่มีผล | ใช่เฉพาะ suspect | – | – |

AIID/AFNC ปี→เดือน→รายการ; ACSC เดือน→สัปดาห์→ต้นทาง; FOTN กลุ่ม→ประเทศรายปี→ปีองค์ประกอบ ย้อนระดับล้างเฉพาะมิติย่อย ชิปกดลบได้ reset เฉพาะแท็บ ทุกกราฟที่ไม่รับมิติติดป้าย ไม่เติมศูนย์เทียม URL เก็บเฉพาะ filter ทั้งสี่แท็บไม่เก็บเนื้อหาข่าว ตรวจ parameter ผิดรูปแบบ ข้อมูลว่างแยก no match/no coverage/excluded suspect

## UX และข้อจำกัด
โทน afmhot/gist_heat ตาม tokens ใน 01 แยกสถานะด้วยข้อความและลาย โหมดระบบทั้ง CSS/Plotly ฟอนต์ไทย fallback ไม่ตัดวรรณยุกต์ ตารางเลื่อนภายในและ pagination ดาวน์โหลดยังครบชุด แยกปุ่มต้นฉบับ/เตรียมแล้ว/กรอง UTF-8 BOM ชื่อไฟล์ปี พ.ศ. คลิกจุดมีรายละเอียดที่อ่านได้โดยไม่ใช้ hover ใช้ filter แทนคลิกได้บนคีย์บอร์ด

ความเสี่ยง: AFNC content ตัด → ค่าขั้นต่ำ; ปีไม่เต็ม/AIID บันทึกล่าช้า → coverage label; EU ฝั่งสนับสนุนรัสเซีย → ห้ามเหมารวมโลก; 8 วันซ้อน → mapping ไม่แบ่งรายวัน; suspect → toggle พร้อมผลต่าง; font ภายนอก → fallback/เลือกใช้ไฟล์ local; เวอร์ชันข้อมูลเปลี่ยน → regression ต้องสอบสวนไม่เปลี่ยน expected เงียบ ๆ
